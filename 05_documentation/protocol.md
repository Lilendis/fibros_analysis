# Протокол анализа фиброза легких

## Структура данных:
- LIF файлы содержат multiple samples
- Каждый sample: 4 канала (Red, Blue, Yellow, Green)
- Автоматическое определение номеров мышей по именам samples

## Выходные данные:
- PNG: композитные изображения 
- CSV: результаты подсчета везикул
- Группировка по мышам автоматическая
